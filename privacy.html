Privacy Policy

stickopedia uploader · last updated 18 August 2026

stickopedia uploader is a personal command-line script used by one person to upload their own videos to their own YouTube channels. This policy describes exactly what it does with data, which is very little.

Data it collects

None. The application has no server, no database and no analytics. It does not collect, transmit, sell or share personal information with anyone.

Google user data it accesses

When authorised, the application uses the Google account's YouTube permissions (youtube.upload and youtube) for exactly two operations:

  • uploading a video file to the authorising channel, with a title, description, tags and a scheduled publication time;
  • setting that video's thumbnail image.

It does not read viewer data, comments, analytics, subscriber information, or any content belonging to other channels.

Where credentials are stored

The OAuth token issued after authorisation is written to a file on the local computer that runs the script, and is used only to refresh access for the operations above. It is never transmitted anywhere except to Google's own API endpoints. It can be revoked at any time from Google Account permissions, or by deleting the local token file.

Limited use

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Third parties

There are none. No data is passed to any third party, because no data leaves the computer except the video and its metadata, which go to YouTube because that is the point.

Changes

If this policy changes, the date at the top of this page changes with it.
